===================================================================
                    KariyerKoçu AI Proje Raporu
===================================================================

1. Özet
--------
KariyerKoçu AI, yapay zekâ destekli kariyer rehberi web sitesi olarak geliştirilmiştir.
Bu proje, kullanıcıların kişisel kariyer hedeflerine uygun meslek önerileri,
CV analizleri ve kariyer yol haritası sunmayı amaçlamaktadır.
Ayrıca, Tawk.to entegrasyonu sayesinde canlı destek hizmetleri de sunulmaktadır.

Projenin canlı hali: https://berkanc0.github.io/kariyerkocu-ai/

-------------------------------------------------------------------

2. Projenin Amacı ve Hedefleri
----------------------------------
- Amacı:
  Kullanıcıların kariyer planlamasında yapay zekâ destekli öneriler ve analizlerle
  karar verme süreçlerini kolaylaştırmak ve modern, kullanıcı dostu bir platform
  sunmaktır.

- Hedefler:
  * Meslek Önerisi: Kullanıcının yetenek ve ilgi alanlarına göre kariyer seçenekleri.
  * CV Değerlendirme: CV analizleri ve geri bildirim.
  * Kariyer Haritası: Hedeflere yönelik adımlar ve yetkinlik geliştirme.
  * Canlı Destek: Tawk.to entegrasyonu ile anlık destek.
  * Kolay Yayınlama: GitHub Pages üzerinden ücretsiz ve kolay erişim.

-------------------------------------------------------------------

3. Kullanılan Teknolojiler ve Araçlar
---------------------------------------
- HTML5, CSS3 ve JavaScript (Web sayfası yapısı, stil ve dinamik özellikler)
- Google Fonts (Inter fontu)
- Tawk.to (Canlı destek entegrasyonu)
- Visual Studio Code & Live Server (Yerel geliştirme ve test)
- GitHub & GitHub Pages (Kaynak kod kontrolü ve ücretsiz barındırma)
- Ek araçlar: Chrome Developer Tools, güvenlik duvarı/antivirüs ayarları

-------------------------------------------------------------------

4. Uygulama Aşamaları
-----------------------
4.1 Tasarım ve Prototip Oluşturma
   - Projenin temel işlevlerinin belirlenmesi (meslek önerisi, CV değerlendirme,
     kariyer haritası, canlı destek).
   - Basit wireframe çizimleri ve kullanıcı dostu tasarım prensipleri uygulanması.
   - Modern ve okunabilir tipografi ile renk paleti seçimi.

4.2 Geliştirme Süreci
   - HTML ve CSS kullanılarak temel sayfa yapısının oluşturulması.
   - JavaScript ile canlı destek (chat widget) için otomatik yanıt mantığının eklenmesi.
   - Tawk.to script kodunun, HTML dosyasının </body> etiketi öncesine eklenmesi.
   - Proje dosyalarının GitHub üzerinden versiyon kontrolü ile takip edilmesi.

4.3 Test ve Yayınlama
   - Live Server aracılığıyla yerel testlerin yapılması ve sorun giderilmesi.
   - Karşılaşılan hataların (“Open a folder or workspace...” gibi) çözülmesi.
   - GitHub Pages ayarlarının (branch ve root dizin) doğru yapılandırılması.
   - Yayınlama sonrası https://berkanc0.github.io/kariyerkocu-ai/ adresinden erişim.

-------------------------------------------------------------------

5. Karşılaşılan Problemler ve Çözümleri
-----------------------------------------
5.1 Yerel Sunucu Problemleri
   - Sorun: Live Server'ın klasör bazlı açılması gerektiği uyarısı.
   - Çözüm: VS Code'da proje klasörünün açılarak Live Server'ın başlatılması.

5.2 Tawk.to Entegrasyonu
   - Sorun: Tawk.to script kodu çalıştırıldığında canlı destek simgesinin görünmemesi.
   - Çözüm: Script kodunun doğru şekilde HTML dosyasına yerleştirilmesi ve HTTPS üzerinden
             erişimin sağlanması.

5.3 GitHub Pages Üzerinde Yayınlama
   - Sorun: 404 hatası alınması.
   - Çözüm: GitHub Pages ayarlarında doğru branch ve root dizinin seçilmesi; index.html dosyasının
             kök dizinde bulunduğunun kontrol edilmesi.

-------------------------------------------------------------------

6. Sonuç ve Gelecek Çalışmalar
----------------------------------
6.1 Sonuçlar:
   - Kullanıcı dostu ve modern bir arayüz geliştirilmiştir.
   - Tawk.to entegrasyonu sayesinde ziyaretçilerle anlık iletişim sağlanmaktadır.
   - GitHub Pages üzerinden ücretsiz ve kolay erişilebilir bir alan adı
     (https://berkanc0.github.io/kariyerkocu-ai/) ile yayınlanmıştır.

6.2 Gelecekteki Çalışmalar:
   - Yapay zekâ öneri algoritmalarının geliştirilmesi.
   - Ek özelliklerin (video konferans, gelişmiş raporlama) eklenmesi.
   - Performans iyileştirmeleri ve güvenlik önlemlerinin artırılması.
   - Responsive tasarımın güçlendirilerek mobil uyumluluğun sağlanması.
